# AI Lessons

Hands-on lessons on working with coding agents, published at https://ai.reidsurmeier.wtf/.

- `index.html` course index; `assets/` shared theme (layout after aihero.dev).
- `telephone/` lesson 01: page, printable worksheet, `setup.sh` (macOS) and `setup.ps1` (Windows) wizards.
- `skills/telephone/SKILL.md` the lesson skill. Install with `npx skills@latest add Reid-Surmeier/ai-lessons -a codex -g`.
- `deploy.sh` rsyncs the site to the droplet.
