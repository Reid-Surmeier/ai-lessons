☎The Telephone Website

Draw a website on paper, hand it to a stranger, and watch an agent build what they read.

Marco Rosso, CTC Faculty · mroso@risd.edu

Reid Surmeier, TA · rsurmeie@risd.edu

What you'll do

Everyone fills in a one page worksheet by hand: a website that does not exist yet, its pages, its colors, a drawing of its homepage. Then the sheets get swapped. You end up holding someone else's site, and they end up holding yours.

You open a coding agent called Codex and type $telephone. The agent interviews you about the sheet, in rounds, until nothing is left to guess. Every time the paper has no answer, you say so and guess out loud. The agent builds the site, publishes it to a real address on GitHub Pages, and hands back the link plus the list of every guess you made.

The gap between what the author drew and what got built is what we look at afterwards. The same gap opens every time you describe something to an agent. This lesson makes it big enough to see.

Set up your computer

One script does the whole setup and tells you what to click at each step. It installs four tools, signs you in twice, and installs the skills. Stop it any time with Ctrl+C; running it again skips what is already done.

Open Terminal

Press ⌘+Space, type Terminal, press Return. A window with a blinking cursor appears. Anything you paste there runs when you press Return.

Download and run the wizard

Copy this line, paste it into Terminal, press Return.

$curl -fsSL https://ai.reidsurmeier.wtf/telephone/setup.sh -o setup.sh && bash setup.sh

The first part downloads the script to a file named setup.sh. The second part runs it.

About Homebrew

Most Macs do not have Homebrew, the installer that developer tools use. You do not need to get it yourself. The wizard checks for it and installs it as its second stage. Expect two things during that stage: the Mac asks for your login password, and nothing shows while you type it, which is normal. Then Apple's command line tools download, which can take five to ten minutes on school wifi. Leave the window open until the wizard moves on.

Open PowerShell

Press the Windows key, type PowerShell, press Enter. A blue or black window with a blinking cursor appears. Anything you paste there runs when you press Enter. Windows 11 is recommended. Windows 10 usually works, but OpenAI only supports it on a best effort basis.

Download and run the wizard

Copy this line, paste it into PowerShell, press Enter.

>irm https://ai.reidsurmeier.wtf/telephone/setup.ps1 -OutFile setup.ps1; powershell -ExecutionPolicy Bypass -File .\setup.ps1

The first part downloads the script to a file named setup.ps1. The second part runs it. Windows may show a blue "User Account Control" box while tools install; click Yes. If Codex offers to set up its Windows sandbox and asks for admin approval, say yes.

The GitHub token

The agent will create a repository and switch on GitHub Pages for you. GitHub lets you mint a token that allows exactly that and nothing else, and that dies after 30 days. The wizard opens the page; here is what it asks you to set.

FieldValue
WhereProfile picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
Token nametelephone-lesson
Expiration30 days
Repository accessAll repositories
Repository permissionsAdministration, Contents, Pages: each set to Read and write. Metadata switches on by itself.
ThenGenerate token. Copy it. Paste it into the wizard. Nothing appears while you paste; press Return.

The token is stored by the GitHub CLI on your machine, never in a file you will see. Treat it like a password: if it ever ends up in a chat or a screenshot, delete it on the same page and make a new one.

The worksheet

Print it, or draw the same boxes on any sheet. Fill it in by hand, in pen. Ten minutes is enough. It asks for nine things: the site's name, who it is for, one sentence on what it is, three colors, a font mood, the list of pages, one thing that must be on it and one that must never be, a drawing of the homepage, and a drawing of one inner page.

Open the worksheet

Draw more than you write. The agent never sees the paper. Everything reaches it through the person holding your sheet, so a labeled box beats a paragraph.

The swap

Fold your sheet once, hand it to someone you did not sit next to, and take one back. From then on:

  • The author is not available. Do not walk over and ask.
  • You answer the agent from the paper. When the paper has no answer, you still answer, but you start with guess:.
  • You build their site, not the site you would have made. Your own ideas are guesses too.

Build it

Make a folder for today, open the agent in it, and start the lesson skill.

$mkdir -p ~/telephone && cd ~/telephone && codex
>mkdir ~\telephone -Force; cd ~\telephone; codex

Codex opens as a chat inside the terminal. Type the line below and press Return.

›$telephone

What happens next, in order:

  1. Check. The agent confirms GitHub is signed in and the skills are present, then asks for the site's name from the paper.
  2. Grill. This is the grill-me skill at work. It asks numbered questions in rounds, each with a recommended answer. Answer every question in the round from the paper, or with guess:. It keeps going until nothing is left open. Expect three to five rounds.
  3. Brief. It writes two files: BRIEF.md, every settled decision, and GUESSES.md, every guess. It asks once whether it missed anything on the paper.
  4. Build. Plain HTML and CSS, the pages the paper listed, the colors it named, the layout it drew. It opens the result so you can compare it to the sheet.
  5. Publish. It creates the repository under your GitHub account, pushes, switches on Pages, and waits until the address answers. Then it prints the link and the guesses.

Keep the paper and the link together. You will show them side by side.

Common questions

The wizard says a tool is "not found" right after installing it

New tools register with the terminal only when it opens. Close the window, open a new one, run the wizard again. It skips finished stages.

Codex sign in fails

Almost always a free ChatGPT account. The CLI needs Plus. Upgrade at chatgpt.com, then run codex login again.

The agent asks me something the paper does not answer

Answer anyway, starting with guess:. Afterwards we compare the guesses with what the author meant, so a guess you wrote down is useful and a guess you hid just looks like a mistake.

It asks too many questions

Answer all of them. The interview stops on its own when the design has no open branches. Short answers are fine.

The link shows a 404

GitHub Pages takes about a minute to build the first time. The agent waits for it; if you checked early, reload.

Can I improve the site after?

After the class has seen it, yes. Before that, no. We want to see what survives one pass through one stranger, so keep the first version as it came out.

It's working if

  • The agent asked questions in numbered rounds before writing any code.
  • Your GUESSES.md has entries, and each one is something the paper really did not say.
  • The live address opens on a phone and shows the pages the paper listed, in the colors it named.
  • The thing that "must never be on it" is not on it.
